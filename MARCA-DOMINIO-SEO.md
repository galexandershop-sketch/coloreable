# Marca, dominio y SEO — Colorable

Fecha: 2026-09-18.

## Nombre sugerido
**Colorable** — "coloreable" en ingles/espanol, corto, pronunciable, disponible probablemente en .com/.app.
Alternativas: ColoreaIA, DibujosIA, ColoringAI, MiLibroParaColorear.
Tagline: "Dibujos para colorear con IA — gratis e imprimible".
Web actual vive en https://coloreable.vercel.app (temporal, cambiar a dominio propio).

## Dominios posibles (verificar disponibilidad)
1. colorable.app (ideal, corto, moderno, ~$15/ano)
2. colorable.io (~$35/ano, tech)
3. coloreaconIA.com (~$10/ano, SEO espanol exacto)
4. dibujosparacolorear.ai (~$60/ano, caro pero keyword exacta)
5. micoloreable.com (~$10/ano, marca propia)
Evitar guiones, numeros, tildes. Preferir .com > .app > .io para AdSense LATAM.

## Donde comprar barato
- Cloudflare Registrar (precio costo, sin renovacion inflada; .com ~$9-10/ano). Recomendado.
- Porkbun (barato y honesto, .com ~$10/ano, promos frecuentes).
- Namecheap (cupones primer ano ~$6, renovacion ~$14; ojo renovacion).
- Evitar GoDaddy (barato el 1er ano, caro al renovar + upsells).
Pasos: comprar -> en Vercel Add Domain -> apuntar nameservers o registro A/CNAME que Vercel indica -> HTTPS automatico.

## Estrategia SEO para atraer publico
### Keywords objetivo (long-tail, baja competencia)
- "dibujos de X para colorear" / "dibujos de X para imprimir" (X = dinosaurios, unicornios, navidad, halloween, animales, profesiones, vehiculos, espacio, oceano, granja).
- "colorear + [personaje/tema] + imprimible / pdf / facil / ninos".
- Ingles (fase 2): "X coloring pages printable free".

### Estructura (Opcion 3)
- 1 pagina estatica por keyword: `/dibujos-de-dinosaurios-para-colorear` con titulo H1 exacto, 6 dibujos pre-generados, texto 150-250 palabras, botones imprimir/descargar, links a categorias hermanas.
- 100 paginas iniciales x 10 visitas/dia = 1.000 visitas/dia de Google Images.
- Sitemap.xml + schema ImageObject + alt text descriptivo por imagen.
- Blog ligero: "10 dibujos de dinosaurios para ninos de 3-5 anos" enlazando a las fichas.

### Contenido y tecnica
- Core Web Vitals: imagenes AVIF/WebP, lazy-load, LCP < 2.5s (Vercel + estatico lo da).
- Mobile-first (80% del trafico es movil de papas).
- safety=true siempre (contenido infantil = AdSense aprobado facil, evita baneos).
- Historial/galeria + compartir WhatsApp = senales de engagement que Google premia.

### Ritmo
- Semana 1: dominio + 20 paginas top keywords + Search Console + AdSense solicitado.
- Semana 2-4: 20 paginas/semana hasta 100 + i18n /en.
- Meta: 1.000 visitas/dia -> AdSense (~$10 RPM) = ~$300/mes base, escalar a 5.000 paginas.
